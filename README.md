# 🦖 토시이 숲

아이만 쓰는 웹·모바일 겸용 대시보드입니다. 설치도 로그인도 없이 브라우저에서 바로 열리고, 기록은 그 기기의 브라우저(localStorage)에만 저장됩니다.

**https://dy-letter.github.io/**

## 무엇을 할 수 있나요

- **홈(숲)** — 지금 시간과 다음 일정, 왼쪽 동그라미 체크리스트(아침 4개 / 저녁 6개), 가운데 토시이, 오늘 10칸 진행 게이지, 먹이 주기·꾸미기 버튼, 공룡선생님 한마디
- **오늘 할 일** — 아침 4개 + 저녁 6개, 총 10개를 한 화면에서 체크·수정
- **도장·스티커판** — 하루 목표를 다 채우면 도장, 주간 도장판, 도장 5개마다 보석 보상
- **오늘 시간표** — 일정과 다음 일정까지 남은 시간 카운트다운, 일정 추가·수정·삭제
- **토시이 꾸미기** — 내 그림으로 캐릭터 바꾸기, 스티커 붙이기, 성장 단계 도감

## 키우기 규칙

- 할 일 1개를 끝내면 먹이 1개 (해제하면 1개 반환)
- 먹이를 주면 누적 먹이가 늘고 Lv.1 ~ Lv.5로 성장 (0 / 5 / 15 / 30 / 50)
- 오늘 10칸을 모두 채우면 게이지가 반짝이고, 먹이가 나타나 토시이가 냠냠 먹는 연출과 함께 누적 먹이 +1 (하루 한 번)

## 쓰는 법

정적 파일만으로 동작합니다. 이 저장소를 그대로 내려받아 `index.html`을 열거나, 좋아하는 정적 호스팅에 올리면 됩니다.

```bash
python3 -m http.server 8080   # http://localhost:8080
```

휴대폰 브라우저에서 열고 "홈 화면에 추가"를 하면 앱처럼 전체 화면으로 쓸 수 있습니다.
