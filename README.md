# 도윤이숲 — 아이 전용 대시보드

아이만 쓰는 웹·모바일 겸용 대시보드입니다. PC(1280×800)와 폰(390×844) 모두에서 가로 스크롤 없이 한 화면에 들어옵니다.
서버·계정·유료 서비스 없이 열리는 정적 앱이고, 기록은 브라우저 `localStorage`에 자동 저장됩니다.

## 바로 열기

```bash
cd projects/toshii-dashboard
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080
```

- 공개 주소: **https://dy-letter.github.io/**
- 저장소: https://github.com/dy-letter/dy-letter.github.io (main)

## 디자인 톤

미니멀·에디토리얼. 겨울 숲 일러스트가 화면을 꽉 채우고(풀블리드, 외곽 액자 테두리 없음), 그 위에 얇은 선과 여백으로 글자가 놓입니다.

- **상자 없음** — 흰 알약 박스·진한 그림자·크림 액자를 쓰지 않고, 가장자리의 옅은 안개(그라데이션 틴트)와 1px 헤어라인으로만 글자를 읽힙니다.
- **선 아이콘** — OS 컬러 이모지 대신 1.5px stroke SVG 라인 아이콘(`index.html` 안의 `<symbol id="i-…">` 스프라이트). 체크리스트·먹이/꾸미기·메뉴·할 일 편집 아이콘 피커·쿠폰 도장까지 모두 같은 세트를 씁니다.
- **타이포** — 제목·날짜·이름은 `Gowun Batang`(얇은 세리프), 라벨·수치는 시스템 산세리프(`Pretendard` → `Apple SD Gothic Neo` → `Noto Sans KR`). 두꺼운 외곽선 글자는 쓰지 않습니다.
- **시계** — 직접 그린 손그림 숫자 SVG(차분한 레드·네이비·머스탯드·세이지그린, 옅은 종이 질감). 흰 스티커 테두리와 드롭섀도우 없이 하늘 위에 바로 놓입니다.
- **게이지** — 3px 얇은 10칸 라인. 채워질 때 차분히 포레스트 그린으로 차고, 10/10이면 반짝임 + 먹이 연출.
- **하단 한마디** — 박스 없이 아래로 스며드는 스크림 위에 `공룡선생님` 라벨 + 세리프 문장 + `다른 말` / `쓰기` 텍스트 버튼.

## 구성 (홈 + 4개 페이지)

홈 화면 **좌측 상단 `☰` 목록 버튼**을 누르면 다섯 화면으로 바로 이동합니다. 바로 옆 **`도윤이숲`**(얇은 세리프)을 누르면 홈으로 돌아옵니다.

| 화면 | 내용 |
| --- | --- |
| **홈** | 겨울 숲 히어로. 상단 손그림 숫자 시계, 그 아래 `11월 25일 (수) · 준비물: 물통, 알림장`(누르면 준비물로 이동), 좌측 원형 체크리스트(아침 4 / 저녁 6), 중앙 빨간 토시이(10살), 캐릭터 아래 10칸 게이지, 먹이 주기·꾸미기 버튼, 좌우 화살표, 하단 공룡선생님 한마디 |
| **토시이** | 토시이 크게 보기 — 현재 성장 단계, 지금까지 먹은 먹이 수, 다음 성장까지 남은 양, 내 그림으로 교체, 스티커, 성장 도감 |
| **쿠폰판** | 30칸 쿠폰판. 토시이가 10칸을 다 채워 먹이를 먹을 때마다 도장 1개. 30개를 모으면 “작은 선물!” 축하와 함께 새 쿠폰판 시작, 완성한 판 수 표시 |
| **기록** | 이번 주 N개 / 이번 달 N개 했어요 (그래프 없이 큰 숫자와 짧은 격려) |
| **준비물** | 오늘·내일 챙길 것 체크, 추가·삭제. 날짜가 바뀌면 ‘내일 준비물’이 ‘오늘 준비물’로 넘어감 |
| **고치기** (목록 하단) | 할 일 이름·아이콘(아침4·저녁6 전체), 시간표, 그림 바꾸기, 소리, 이름 되돌리기, 기록 지우기 |

## 기본 체크리스트

- 아침 4개: 아침식사 · 세안/양치 · 옷입기 · 준비물체크
- 저녁 6개: 가방정리 · 저녁식사 · 목욕 · 공부 · 놀기 · 잠자기

홈 왼쪽 원형은 **12시 전에는 아침 4개, 12시 이후에는 저녁 6개**가 자동으로 보이고, 왼쪽 위 `아침 / 저녁` 버튼으로 언제든 바꿀 수 있습니다(그날 동안 유지).

## 보상 규칙

1. 할 일 1개를 끝내면 **먹이 1개**(해제 시 1개 반환).
2. 먹이 주기 버튼 → 남은 먹이가 줄고 **누적 먹이**가 늘어 Lv.1~Lv.5 성장(0 / 5 / 15 / 30 / 50).
3. **오늘 10칸을 모두 채우면**(하루 한 번):
   - 게이지가 반짝이고,
   - 먹이 아이콘이 토시이에게 날아가고,
   - 토시이가 통통 튀며 냠냠 먹는 연출 + 얇은 반짝이,
   - 누적 먹이 +1, **쿠폰 도장 +1**.

## 저장값 (localStorage `toshii.forest.v1`)

`todos`·`schedule`·`stickers`의 아이콘은 이제 선 아이콘 이름(`bowl`, `moon`, `star` …)으로 저장됩니다.
예전에 저장된 이모지 값은 읽을 때 `app.js`의 `EMOJI_MAP`으로 자동 변환되므로 기존 기록이 그대로 살아납니다.

## 토시이 그림

- 기본 그림은 아이가 직접 그린 토시이를 몽글몽글한 빨간 크레용 질감으로 다듬은 `assets/toshii-default.webp`(투명 WebP)입니다.
- **그림 바꾸기**: 목록 → `그림 바꾸기`, 또는 토시이 화면 → `그림 올리기`. 560px로 줄여 그 기기에만 저장되고 서버로 올라가지 않습니다.
- 원본 사진과 생성 원본은 `assets/source/`에 있습니다(배포에는 미포함).

## 파일

```
index.html      화면 구조 + 선 아이콘 스프라이트
styles.css      디자인·반응형
app.js          상태·저장·모든 동작과 아이콘 렌더링
manifest.json   홈 화면에 추가(PWA)
assets/         겨울 숲 배경(forest-bg.jpg), 토시이 그림, 아이콘, 폰트
screenshots/    검증 스크린샷(웹/모바일) + report.json
test_check.py   로컬 Playwright 검증 스크립트
live_check.py   배포 주소(https://dy-letter.github.io/) 검증 스크립트
```

## 검증
