# 🦖 토시이 숲

아이만 쓰는 웹·모바일 겸용 대시보드입니다. 설치도 로그인도 없이 브라우저에서 바로 열리고, 기록은 그 기기의 브라우저(localStorage)에만 저장됩니다.

**https://dy-letter.github.io/**

## 구성

홈 왼쪽 위 `☰` 목록 버튼으로 다섯 화면을 오갑니다.

- **홈** — 실시간 시간과 다음 일정, 왼쪽 동그라미 체크리스트(아침 4개 / 저녁 6개), 가운데 빨간 토시이(10살), 토시이 아래 10칸 게이지, 먹이 주기·꾸미기 버튼, 공룡선생님 한마디
- **토시이** — 토시이를 크게. 성장 단계, 지금까지 먹은 먹이 수, 다음 성장까지 남은 양, 내 그림으로 바꾸기, 스티커, 성장 도감
- **쿠폰판** — 30칸 쿠폰판. 토시이가 10칸을 다 채워 랜덤 먹이를 먹을 때마다 도장 1개, 30개를 모으면 “작은 선물!”과 새 쿠폰판
- **기록** — 이번 주 N개 / 이번 달 N개 했어요
- **준비물** — 오늘·내일 준비물 체크, 추가·삭제

## 키우기 규칙

- 할 일 1개를 끝내면 먹이 1개 (해제하면 1개 반환)
- 먹이를 주면 누적 먹이가 늘고 Lv.1 ~ Lv.5로 성장 (0 / 5 / 15 / 30 / 50)
- 오늘 10칸을 모두 채우면 게이지가 반짝이고, 랜덤 먹이(🍖 🥕 🥦 …)가 나타나 토시이가 냠냠 먹는 연출과 함께 누적 먹이 +1, 쿠폰 도장 +1 (하루 한 번)

## 쓰는 법

정적 파일만으로 동작합니다. 이 저장소를 그대로 내려받아 `index.html`을 열거나, 좋아하는 정적 호스팅에 올리면 됩니다.

```bash
python3 -m http.server 8080   # http://localhost:8080
```

휴대폰 브라우저에서 열고 "홈 화면에 추가"를 하면 앱처럼 전체 화면으로 쓸 수 있습니다.
