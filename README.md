# 🌲 도윤이숲 — 아이 전용 대시보드

아이만 쓰는 웹·모바일 겸용 대시보드입니다. PC(1280×800)와 폰(390×844) 모두에서 가로 스크롤 없이 한 화면에 들어옵니다.
서버·계정·유료 서비스 없이 열리는 정적 앱이고, 기록은 브라우저 `localStorage`에 자동 저장됩니다.

## 바로 열기

```bash
cd projects/toshii-dashboard
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080
```

- 공개 주소: **https://dy-letter.github.io/**
- 저장소: https://github.com/dy-letter/dy-letter.github.io (main)

## 구성 (홈 + 4개 페이지)

홈 화면 **좌측 상단 `☰` 목록 버튼**을 누르면 다섯 화면으로 바로 이동합니다. 바로 옆 **`도윤이숲`**(얇은 세리프)을 누르면 홈으로 돌아옵니다.

| 화면 | 내용 |
| --- | --- |
| **홈** | 겨울 숲 히어로. 상단 손그림 콜라주 느낌의 실시간 시계, 그 아래 얇은 세리프로 `11월 25일 (수) · 준비물: 물통, 알림장`(누르면 준비물로 이동), 좌측 동그라미 체크리스트(아침 4 / 저녁 6), 중앙 몽글몽글 빨간 토시이(10살), 캐릭터 아래 10칸 게이지, 먹이 주기·꾸미기 버튼, BACK/NEXT, 하단 공룡선생님 한마디 |
| **토시이** | 토시이 크게 보기 — 현재 성장 단계, 지금까지 먹은 먹이 수, 다음 성장까지 남은 양, 내 그림으로 교체, 스티커, 성장 도감 |
| **쿠폰판** | 30칸 쿠폰판. 토시이가 10칸을 다 채워 랜덤 먹이를 먹을 때마다 도장 1개. 30개를 모으면 “작은 선물!” 축하와 함께 새 쿠폰판 시작, 완성한 판 수 표시 |
| **기록** | 이번 주 N개 / 이번 달 N개 했어요 (그래프 없이 큰 숫자와 짧은 격려) |
| **준비물** | 오늘·내일 챙길 것 체크, 추가·삭제. 날짜가 바뀌면 ‘내일 준비물’이 ‘오늘 준비물’로 넘어감 |
| **고치기** (목록 하단) | 할 일 이름·그림(아침4·저녁6 전체), 시간표, 그림 바꾸기, 소리, 이름 되돌리기, 기록 지우기 |

## 기본 체크리스트

- 아침 4개: 아침식사 · 세안/양치 · 옷입기 · 준비물체크
- 저녁 6개: 가방정리 · 저녁식사 · 목욕 · 공부 · 놀기 · 잠자기

홈 왼쪽 동그라미는 **12시 전에는 아침 4개, 12시 이후에는 저녁 6개**가 자동으로 보이고, 왼쪽 위 `🌅 아침 / 🌙 저녁` 버튼으로 언제든 바꿀 수 있습니다(그날 동안 유지).

## 보상 규칙

1. 할 일 1개를 끝내면 **먹이 1개**(해제 시 1개 반환).
2. 먹이 주기 버튼 → 남은 먹이가 줄고 **누적 먹이**가 늘어 Lv.1~Lv.5 성장(0 / 5 / 15 / 30 / 50).
3. **오늘 10칸을 모두 채우면**(하루 한 번):
   - 게이지가 반짝이고,
   - 🍖·🥕·🥦·🍎·🍇·🍌 중 **랜덤 먹이**가 나타나 토시이에게 날아가고,
   - 토시이가 통통 튀며 냠냠 먹는 연출 + 하트·반짝이,
   - 누적 먹이 +1, **쿠폰 도장 +1**.

## 토시이 그림

- 기본 그림은 아이가 직접 그린 토시이를 몽글몽글한 빨간 크레용 질감으로 다듬은 `assets/toshii-default.webp`(투명 WebP)입니다.
- **그림 바꾸기**: 목록 → `그림 바꾸기`, 또는 토시이 화면 → `🖼 그림 올리기`. 560px로 줄여 그 기기에만 저장되고 서버로 올라가지 않습니다.
- 원본 사진과 생성 이미지는 `assets/source/`에 있습니다(배포에는 미포함).

## 파일

```
index.html      화면 구조
styles.css      디자인·반응형
app.js          상태·저장·모든 동작
manifest.json   홈 화면에 추가(PWA)
assets/         겨울 숲 배경(forest-bg.jpg), 토시이 그림, 아이콘, 폰트
screenshots/    검증 스크린샷(웹/모바일) + report.json
test_check.py   Playwright 검증 스크립트
```

## 검증

`test_check.py` (Playwright / Chromium)

- 1280×800, 390×844 모두 **콘솔 에러 0 · 페이지 에러 0 · 실패 요청 0**
- 상단 시계(커스텀 SVG 숫자)·날짜+준비물 요약·`도윤이숲` 홈 링크 확인
- 모든 화면 가로 넘침(`overflow-x`) 0
- 체크 토글·먹이 주기·해제 환불·10/10 보상 연출(반짝 + 랜덤 먹이 + 냠냠 + 쿠폰 +1)·쿠폰 30칸 완성과 새 판 시작·기록 집계·준비물 추가/체크/삭제·그림 업로드/되돌리기·시간표 편집·목록 이동·새로고침 후 저장 확인
